# Golden fixtures

`snapshot-hash.json` is generated by the TypeScript implementation
(`packages/usage-core`) — it is the byte-level truth the Go
`Snapshot.HashPayload` must reproduce, because the server's dedup hash runs
over exactly this serialization.

Regenerate after an intentional usage-core schema change by running the
generation script from the repo root and committing the diff together with
the corresponding usage-core change:

```bash
node --experimental-strip-types scripts/clients-go-gen-goldens.mjs \
  > clients/go/internal/contract/goldens/snapshot-hash.json
```

Never hand-edit the file: the whole point is that TypeScript, not a human,
defines the expected bytes.
